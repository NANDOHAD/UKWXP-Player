# UKWXP Player

## 概要

このリポジトリは、DirectX9向けアクションゲーム「Ultimate Knight ウィンダムXP」対応の機体MODをUnity上で再生するプレイヤーアプリケーション開発プロジェクトです。


> 本プロジェクトは原作の権利者による公式ソフトウェアではありません。原作の再現研究およびUnity上で動作するアプリケーション制作を目的とします。原作データ・実行ファイル・解析資料の取り扱いは、利用者の環境と適用されるライセンス・法令に従ってください。


## 現在の仕様

- Unity **6000.6.0f1**を対象とします。
- 起動シーンは`Assets/Scenes/MechSelection.unity`。選択後は`StandaloneTestPlay.unity`で戦闘します。画面はシーン配置のuGUIで、ロード表示・再戦・機体選択への復帰に対応します。
- ルートディレクトリに存在する`Windom_Data\Robo`配下の各機体フォルダから、実形式がAN2である`Script.ani`を読み込み、プレイヤー機体と相手機体を組み立てます（旧ANI形式は読み込まれません）。
- 原作完全再現や、原作EXEとの全tick・全描画・全音響一致を達成したものではありません。未確定の挙動は、原作確定・原作高確度・原作推定・RealAniObserved・Unity代替の区分で管理します。


## 機体データ

機体フォルダには、機体によって以下のファイルが含まれます。

- `Script.ani`／`.ani`: アニメーション、HOD構造、ANIスクリプト
- `.hod`: 単体HOD
- `Script.spt`: 機体パラメータ設定など
- `.x`／`.png`: 機体モデル、テクスチャ（基本的に暗号化済みのもの）
