# UKWXP Player

## 概要

このリポジトリは、DirectX9時代のゲーム「Ultimate Knight ウィンダムXP」をUnity上で再現するクローンゲーム制作プロジェクトです。


> 本プロジェクトは原作の権利者による公式ソフトウェアではありません。原作の再現研究およびUnity上でのクローンゲーム制作を目的とします。原作データ・実行ファイル・解析資料の取り扱いは、利用者の環境と適用されるライセンス・法令に従ってください。

## 現在の仕様

- Unity **6000.6.0f1**を対象とします。
- `StandaloneTestPlay`シーンを独立ゲーム実行入口として使用します。
- `Windom_Data\Robo`配下の機体フォルダから、実形式がAN2である`Script.ani`を読み込み、プレイヤー機体と相手機体を組み立てます。
- 既存の編集UI・機体選択・ANI／AN2／HOD／SPT互換処理は、開発用編集・検証基盤として維持します。
- 独立実行側は、機体ごとの状態・入力・ANI／SPTランタイム・60Hzシミュレーション時計を分離して管理します。
- 現在の独立実行基盤には、2機体セッション、移動、射撃・格闘、最小限の命中・被弾・撃破、HUD、戦闘終了・再戦・終了処理が含まれます。
- 実装済みの攻撃・演出は、原作根拠に基づくCoreと、Unity上での描画・物理・音声上の代替実装を分けて扱います。
- 原作完全再現や、原作EXEとの全tick・全描画・全音響一致を達成したものではありません。未確定の挙動は、原作確定・原作高確度・原作推定・RealAniObserved・Unity代替の区分で管理します。


## 機体データ

機体フォルダには、機体によって以下のファイルが含まれます。

- `Script.ani`／`.ani`／`.an2`: アニメーション、HOD構造、ANIスクリプト
- `.hod`: 単体HOD
- `Script.spt`: 機体パラメータ、BURNER設定など
- 暗号化された`.x`および`.png`: 3Dモデル、テクスチャ


旧ANIは必要に応じて、元ファイルを変更しない非上書きのAN2コピーへ変換できます。AN2出力は原作の200枠上限を考慮し、追加アニメーションを末尾に保持します。保存後は再読込みと内容照合を行います。
