# UKWXP Player

## 概要

このリポジトリは、DirectX9時代のゲーム「Ultimate Knight ウィンダムXP」をUnity上で再現するゲーム制作プロジェクトです。


> 本プロジェクトは原作の権利者による公式ソフトウェアではありません。原作の再現研究およびUnity上でのクローンゲーム制作を目的とします。原作データ・実行ファイル・解析資料の取り扱いは、利用者の環境と適用されるライセンス・法令に従ってください。


## 現在の仕様

- Unity **6000.6.0f1**を対象とします。
- `StandaloneTestPlay`シーンを独立ゲーム実行入口として使用します。
- `Windom_Data\Robo`配下の機体フォルダから、実形式がAN2である`Script.ani`を読み込み、プレイヤー機体と相手機体を組み立てます。
- 原作完全再現や、原作EXEとの全tick・全描画・全音響一致を達成したものではありません。未確定の挙動は、原作確定・原作高確度・原作推定・RealAniObserved・Unity代替の区分で管理します。


## 機体データ

機体フォルダには、機体によって以下のファイルが含まれます。

- `Script.ani`／`.ani`／`.an2`: アニメーション、HOD構造、ANIスクリプト
- `.hod`: 単体HOD
- `Script.spt`: 機体パラメータ設定など
- `.x`／`.png`: 機体モデル、テクスチャ（基本的に暗号化されているものとする）
